# 🌤️ Weather App

A simple and responsive weather application built with **HTML, CSS, and JavaScript**.

The application allows users to search for a city and view its current weather information. This project was built as part of my **Web Development learning journey** to practice JavaScript, API integration, DOM manipulation, and responsive UI development.

---

## ✨ Features

- 🔍 Search for weather by city name
- 🌡️ Display current temperature and weather information
- 🌤️ Display weather conditions
- 💧 Display additional weather details
- 💨 Display wind information
- 🖼️ Weather-related visuals
- 📱 Responsive user interface
- ⚡ Dynamic content using JavaScript
- ❌ Handles invalid city searches

---

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| **HTML5** | Structure of the application |
| **CSS3** | Styling and responsive design |
| **JavaScript** | Application logic and interactivity |
| **Weather API** | Fetching weather data |
